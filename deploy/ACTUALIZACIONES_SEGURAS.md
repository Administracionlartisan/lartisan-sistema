# Actualizaciones seguras

1. Confirmar que el respaldo automático más reciente se completó y descargar una copia antes del cambio.
2. Crear un archivo de la versión publicada y anotar fecha, versión y responsable.
3. Publicar la nueva versión fuera de horario de venta.
4. Ejecutar el chequeo de salud y probar acceso, venta, caja, stock y sincronización.
5. Si una prueba falla, restaurar inmediatamente el archivo anterior y la copia de base de datos verificada.

Nunca se reemplaza una versión sin conservar la anterior. El circuito fiscal ARCA queda fuera de este procedimiento hasta su implementación.
