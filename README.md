# Sistema L'Artisan

Instantánea del código web y de la API PHP para colaboración. Incluye cambios locales en desarrollo, entre ellos el circuito de solicitud y aprobación de egresos de mercadería. Su presencia aquí no implica que estén publicados en producción ni que el recorrido completo esté validado.

Por seguridad no se incluyen respaldos, paquetes de despliegue, registros, configuraciones privadas ni el historial anterior. Esta es una instantánea inicial, no un clon completo del historial. Las configuraciones de prueba y ejemplos deben revisarse y adaptarse antes de usarse.

Para comenzar, consultar `dev/README.md`, `donweb-api/README.md` y `AGENTS.md`. No incorporar credenciales, datos reales ni configuraciones privadas a este repositorio público.
